## Interactive Icons

Custom icons that animate or change based on the state of the button/link they're inside.

- **`ArrowLeftInteractiveIcon`** / **`ArrowRightInteractiveIcon`** / **`ArrowUpRightInteractiveIcon`** — like their Phosphor counterparts but translate in the direction they point on hover. Have a `hiddenByDefault` prop: when `false` (default), the arrow is always visible and translates away on hover; when `true`, it starts hidden and appears on hover; when `'if-can-hover'`, behaves like `true` on hover-capable devices and `false` on touch-only devices. `ArrowUpRightInteractiveIcon` is used by `Link` as the default `addonAfter` when `target="blank"`.
- **`CaretDownInteractiveIcon`** — like `CaretDownIcon` but rotates 180° when the parent element is "open" (matches `[open]`, `:popover-open`, `[aria-expanded=true]`, etc.).
- **`CaretUpDownInteractiveIcon`** — like `CaretUpDownIcon` but highlights one direction based on the `direction` prop (`'ascending'` or `'descending'`). Used by `Table` column headings to show sort state.
- **`SidebarLeftInteractiveIcon`** / **`SidebarRightInteractiveIcon`** — like their Phosphor counterparts but the sidebar panel appears filled when the parent element is "checked" (matches `[aria-checked=true]`, `[aria-pressed=true]`, `[aria-selected=true]`). Used by `Pane.ToggleButton`.

## Dynamic Icons

Custom icons whose appearance depends on a data prop.

- **`CalendarDynamicIcon`** — displays a calendar with the current (or specified) day number. Has a `date` prop (number or `Date`, defaults to `new Date()`).
- **`HourglassDynamicIcon`** — displays an hourglass with variable fill level. Has a `filledPercentage` prop (0–100, defaults to 0).

## Other Custom Icons

- **`LoadingIcon`** — animated "spinner" (three dots/diamonds that grow and shrink in a staggered pattern). Not a traditional spinning circle. Used by `Button` (with `loading={true}`). **Do not add `animate-spin`** — it has its own animation.
- **`CopyInteractiveIcon`** — like `CopyIcon` but animates when the `copied` prop is `true`. Used by `CopyButton`.
